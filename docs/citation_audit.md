## Citation rule

A citation is usable only after source existence, agency or authorship, release year, persistent source location, and claim relevance are verified.

## Prohibited

- Simulated citations
- Unverified DOI claims
- Unsupported causal claims
- Results citations before analysis scripts generate outputs
