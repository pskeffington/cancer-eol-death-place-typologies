# Dataset and Variable Plan

## Purpose

Define the public-data design for county-level typologies of cancer place of death and end-of-life care intensity.

## Current status

Early-stage topic selection.

## Required design decisions

| Decision | Status | Notes |
|---|---|---|
| Primary outcome dataset | Pending | Candidate public mortality or health-services source |
| Geographic unit | Pending | County, state, region, or other unit |
| Cancer cohort definition | Pending | ICD or source-specific definition |
| Place-of-death outcome | Pending | Define categories and exclusions |
| Care-intensity inputs | Pending | Candidate Dartmouth Atlas or related sources |
| Hospice and healthcare supply inputs | Pending | Candidate public sources |
| Rurality and socioeconomic inputs | Pending | Candidate public sources |

## Candidate variable groups

- Cancer mortality and place of death
- Hospice access or hospice-use proxies
- End-of-life care intensity indicators
- Healthcare supply and access
- Rurality and geography
- Socioeconomic context
- Age structure and population denominators

## Validation boundary

This repository should remain a variable-mapping and design workspace until the dataset, typology outcome, and linkage plan are frozen. Avoid causal language until identification limits are documented.
