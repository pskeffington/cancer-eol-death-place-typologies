# Project Description

This repository contains an early-stage open-data health-services research scaffold for county-level typologies of cancer place of death and end-of-life care intensity. It is designed for dataset selection, variable mapping, source documentation, and claims-boundary development before manuscript prose expands.

The project remains exploratory until the defensible public dataset, typology outcome, geographic unit, and linkage strategy are frozen.

## Short description

Open-data scaffold for cancer place-of-death and end-of-life care typologies with dataset and variable-map gates pending.

## Scope boundary

Keep ecological and county-level inference limits explicit. Do not use causal language until the data design and identification limits are documented.
